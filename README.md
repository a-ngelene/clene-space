# Clene Space
It is a custom-built web portfolio designed to display my personal artworks and other things related to me. This project not only serves as an activity in my course (Web Programming) but also to rekindle my passion for visual arts.

## Project Files
- HTML: index.html, about.html, artworks.html, others.html
- Stylesheet: style.css
- Assets: Resources/ directory

## Note on Assets
All included images are either my original property or design elements sourced from Canva.
